## 🚀 Projeto em destaque

### SafeGrow

Aplicação web informativa com foco em conscientização sobre **segurança digital infantil**, desenvolvida como projeto interdisciplinar entre os cursos de ADS e Sistemas de Informação na PUC Minas.

- Layout responsivo, menu interativo e barra de pesquisa com filtragem de conteúdos
- Renderização dinâmica de cards e consumo de dados via API REST simulada (JSON Server)
- Manipulação de DOM, requisições com `fetch` e integração front-end/API

`HTML` • `CSS` • `JavaScript` • `Bootstrap` • `JSON Server` • `Git`

🔗 [Repositório](https://github.com/ICEI-PUCMinas-PSG-SI-TI/2016-1-tiaw-g4-safegrow) · [Aplicação ao vivo](https://safe-grow.netlify.app/)
